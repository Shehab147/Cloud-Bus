# Supplied template style map

The supplied `css/globals.css` and `css/theme.css` are the authoritative visual source. `globals.css` is a Tailwind CSS v4 source file: its utility classes are generated from the theme tokens at build time, while its named classes remain available directly. The application imports it unchanged and adds only application-specific rules in `frontend/src/custom.css`.

| UI need | Supplied classes/tokens used | Notes |
|---|---|---|
| Layout | `container`, `grid`, `flex`, `space-y-*`, `gap-*`, responsive `sm:*`/`md:*`/`lg:*` | Tailwind utilities are generated by the template's `@import "tailwindcss"`. |
| Typography | `text-*`, `font-*`, `tracking-*`, `text-foreground`, `text-muted-foreground` | Noto Sans token is supplied; system fallback is used when it is unavailable. |
| Cards/surfaces | `rounded-lg`, `border`, `border-border`, `bg-card`, `bg-muted`, `shadow-sm` | Template radius, border, foreground, and surface tokens support both themes. |
| Buttons | `bg-primary`, `text-primary-foreground`, `bg-secondary`, `text-secondary-foreground`, `text-destructive`, hover/focus utilities | No named button component class exists; reusable React `Button` composes supplied utilities. |
| Inputs | `border-input`, `bg-background`, `text-foreground`, `focus-visible:ring-ring`, `rounded-md` | No named input class exists; reusable React `Field` composes utilities. |
| Tables | `table`, `divide-y`, `border-border`, responsive overflow utilities | No named table component class exists. |
| Tabs | border, spacing, foreground/background, and state utilities | No named tab class exists; React state/router links provide behavior. |
| Navigation | layout, border, background, text, responsive and sticky utilities | No named navigation class exists. |
| Dialogs | fixed/inset/layout/surface utilities; `animate-slideDownAndFade` is supplied | Native `<dialog>` is wrapped in React for focus and escape behavior. |
| Alerts/status | `text-destructive`, `text-warning`, `text-info`, `text-success` and matching surface/border utilities | Status always includes a text label, not color alone. |
| Pagination | `paginate_wrapper`, size/color/rounded variants, plus button utilities | The app uses a compact accessible React wrapper with supplied utilities. |
| Loading | `admin-dashboard-shimmer`, `animate-spin`, opacity utilities | Template shimmer respects reduced motion; the app also uses a restrained spinner. |
| Maps | `.dash-tail-app .leaflet-container` z-index rules | Leaflet container height and marker fixes are the only map-specific additions in `custom.css`. |
| Responsive helpers | standard responsive variants, `page-min-height`, `layout-padding`, line clamps | Mobile navigation behavior is implemented with React state. |
| Theme | `.dark`, `.theme-*` including `.theme-violet` | The app uses `theme-violet` and persists light/dark preference. |

Unavailable as named template classes: application shell, skip link, button variants, field wrappers, modal layout, toast viewport, empty state, and map sizing. These are composed from existing template utilities. Only behavior that cannot be expressed reliably as scanned utilities (Leaflet dimensions, native dialog backdrop, mobile menu breakpoint, reduced-motion fallback) is scoped in `frontend/src/custom.css`.
